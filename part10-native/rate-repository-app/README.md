# Rate Repository App

A simple app to rate repositories on GitHub. It uses GraphQL to fetch and save the data. It also uses Apollo Client to manage the GraphQL client. The app is built using React Native and Expo. The app uses the GitHub API to fetch the data. You can find the code for the server part [here](https://github.com/pk504b/full-stack-open/tree/main/part10-native/rate-repository-app).

## Tech Stack

- React Native
- Expo
- GraphQL
- Apollo Client
